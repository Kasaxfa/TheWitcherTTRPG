# Кодекс ремесленника — НРИ «Ведьмак»

Интерактивный справочник рецептов алхимии и ремесленных чертежей.

В каталоге 147 записей: 22 формулы алхимии, 60 чертежей оружия, 51 чертёж брони и 14 схем компонентов. У каждой записи указана страница основной книги правил.

## Запуск

Сайт статический. Откройте index.html в браузере. GitHub Pages может публиковать файлы из ветки main, папки /(root).

## База каталога

SQLite-база в database/catalog.sqlite3 хранит предметы, рецепты, результаты и строки ингредиентов, источники и заготовки для описаний ингредиентов, характеристик экипировки и эффектов алхимии. Записи карточек, которых пока нет в проверенных данных книги, оставлены пустыми.

Для экспорта данных из SQLite в data.js выполните:

    python3 tools/build_catalog.py

Файл data.js — статический JSON-совместимый вывод из базы, который использует сайт. При изменении базы сначала запустите эту команду, затем сохраните в Git и базу, и data.js.

При отсутствии файла базы скрипт создаст его из database/schema.sql и database/seed_recipes.json. Флаг --rebuild-db пересоздаёт базу из исходного снимка рецептов:

    python3 tools/build_catalog.py --rebuild-db

Проверка целостности:

    python3 tools/build_catalog.py --check

Личные инвентари не записываются в общую SQLite-базу сайта. Для статического GitHub Pages они будут сохраняться в браузере и переноситься отдельным JSON-файлом.

## Публикация через GitHub Pages

В репозитории откройте Settings → Pages, выберите Deploy from a branch, затем ветку main и папку /(root).
