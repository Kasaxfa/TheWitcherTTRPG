# Кодекс ремесленника — НРИ «Ведьмак»

Интерактивный справочник рецептов алхимии и ремесленных чертежей.

В каталоге 147 записей: 22 формулы алхимии, 60 чертежей оружия, 51 чертёж брони и 14 схем компонентов. У каждой записи указана страница основной книги правил.

## Использование

Сайт статический: достаточно открыть `index.html` в браузере. В нём есть поиск по названию и ингредиентам, фильтры по типу и уровню ремесла, а карточки раскрывают состав, сложность и время изготовления.

## Публикация через GitHub Pages

В репозитории откройте **Settings → Pages**, выберите источник **Deploy from a branch**, затем ветку `main` и папку `/(root)`.

## Структура

- `index.html` — разметка сайта
- `styles.css` — оформление
- `data.js` — справочные данные
- `app.js` — фильтры и взаимодействие
