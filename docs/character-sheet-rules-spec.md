# Спецификация листа персонажа: НРИ «Ведьмак»

Статус: формулы и стартовые данные сверены по русскому изданию, страницы 20–70. Предоставленный PDF — читаемый скан без текстового слоя; страницы проверены визуально. Правила, для которых этих страниц недостаточно, явно оставлены ручными.

## 1. Границы правил

- Система: The Witcher Tabletop Roleplaying Game от R. Talsorian Games. Лист не использует характеристики, классы, КД или уровни D&D.
- Базовый источник полей: официальный четырёхстраничный [Witcher Character Sheet](https://rtalsoriangames.com/wp-content/uploads/2018/08/witcher-character-sheet.pdf).
- Основной источник правил — русский экземпляр, страницы 20–70. Для ошибок печати и более поздних уточнений учитываются [официальная errata для 1-й и 2-й печати](https://rtalsoriangames.com/wp-content/uploads/2022/03/RTG-WI-WitcherCoreErratav4.pdf) и ответы разработчика. Версия правил сохраняется в записи персонажа.
- PDF является сканом: страницы читаемы визуально, но текст нельзя надёжно извлечь автоматически. Формулы ниже сверены по страницам и таблицам, а не по OCR.

## 2. Поля листа

| Блок | Поля | Способ ввода / изменения |
|---|---|---|
| Персонаж | Имя, игрок, раса, пол, возраст, происхождение, текущее местоположение | Свободный ввод/выбор. Текущее местоположение нужно для расчёта социального отношения к расе |
| Жизненный путь | Родина, судьба семьи и родителей, положение семьи, братья/сёстры, важные события по десятилетиям, союзники, враги, романтические связи, личный стиль и ценности | Результат таблицы или выбор игрока; повествовательный результат и выданные им механические бонусы/предметы хранятся раздельно с источником |
| Социальное отношение к расе | Равенство, терпимость, опасение или ненависть | Определяется по текущей территории и расе таблицей книги; мастер может вручную переопределить результат |
| Профессия | Профессия, определяющий навык, навыки профессии, ветвь и умения дерева, энергия, доступная магия, стартовое снаряжение | Заполняется по справочнику профессий; развитие и выбор ветвей меняются во время игры |
| Характеристики | INT, REF, DEX, BODY, SPD, EMP, CRA, WILL, LUCK | Девять основных характеристик. База, бонусы расы/мутаций и временные модификаторы хранятся раздельно |
| Навыки | Навыки, сгруппированные по ведущей характеристике; рейтинг каждого навыка | Рейтинг вводится и развивается игроком; видимые бонусы от происхождения, брони и способностей показываются отдельно |
| Производные показатели | STUN/Устойчивость, RUN/Бег, LEAP/Прыжок, HP/ПЗ, STA/Выносливость, ENC/Переносимый вес, REC/Отдых, урон ближнего боя, удар рукой/ногой | Расчёт или таблица по разделу 3. Энергия задаётся профессией и её умениями |
| Текущее состояние | Текущие ПЗ, Выносливость и Удача; ранения; зависимости и дни без дозы; состояния; потраченные ресурсы; прочность оружия и брони | Меняется во время игры. Удача восстанавливается только действием «Начать сессию»; временные штрафы и потери отделены от базовых значений |
| Броня | Предмет, зоны тела, SP по зонам, текущая прочность/повреждение, EV, эффекты и сопротивления | Выбор из каталога и состояние конкретного экземпляра; EV отделяется от веса и ENC |
| Оружие и щит | Основное и запасное оружие, WA, урон/тип, надёжность, число рук, дальность, эффект, скрытность, улучшения; щит и его характеристики | Выбор предмета из каталога; текущая надёжность хранится отдельно от базовой |
| Снаряжение | Предметы, количество, заметки, вес, ценность, компоненты и переносимый вес | Выбор из каталога или собственный предмет; ссылки по постоянным ID, состояние принадлежит конкретному персонажу |
| Магия | Заклинания, знаки, инвокации, порчи, ритуалы, стоимость Выносливости, эффект, дальность, длительность, время, СЛ; Энергия | Разделы показываются по применимости профессии. Список изученного и затраты — данные персонажа; неизвестные расходы и эффекты не вычисляются |
| Развитие | Очки улучшения, рейтинги навыков и умений дерева, изменения характеристик, репутация | Очки и выбранные улучшения вводятся игроком; стоимость следующего уровня считается по проверенным правилам раздела 3 |
| Заметки | Заметки, кампанийный журнал и дополнительные детали | Свободный текст |

В жизненном пути часть таблиц выдаёт игровые последствия: предметы, репутацию, бонусы навыков и характеристики либо состояния вроде зависимости. Каждое такое последствие хранится отдельным структурированным эффектом со ссылкой на результат таблицы; не выводить его из прозы события.

## 3. Таблица вычислений и правил

Автоматизировать можно только строки с зафиксированным правилом. Бросок, потраченное состояние и модификатор окружения остаются явными действиями игрока/ведущего.

| Результат | Проверенное правило | Источник и граница автоматизации |
|---|---|---|
| Создание характеристик | Девять бросков d10; результат 1–2 перебрасывается, затем значения распределяются по девяти параметрам. Альтернатива — распределение 60/70/75/80 очков по уровню игры. Обычный максимум параметра — 10; раса/мутация может дать исключение. | Книга, стр. 47; errata к лимитам. Сохранять способ создания и источник каждого бонуса. |
| Физическая основа | B = floor((BODY + WILL) / 2). По таблице: HP = 5 × B, STA = 5 × B, REC = B, STUN = min(B, 10). Дробные производные округляются вниз. | Книга, стр. 47–48; совпадает с официальным разъяснением STUN. Таблица содержит строки B=2…13; значения вне таблицы не экстраполировать без правила. |
| Проверка STUN | Проверка проходит, если результат d10 строго ниже STUN. | Книга, стр. 47; уточнение разработчика. |
| RUN и LEAP | RUN = SPD × 3 метров за ход; LEAP = floor(RUN / 5) метров. | Книга, стр. 47–48. |
| Переносимый вес | ENC = BODY × 10 кг без замедления; предел подъёма — BODY × 50 кг. За каждые полные 5 кг сверх ENC, пока вес не превышает предел, REF, DEX и SPD уменьшаются на 1, минимум до 1. | Книга, стр. 48. Вес инвентаря суммируется по предметам; EV брони не является весом. |
| Урон тела | По BODY берётся бонус ближнего боя и отдельные значения удара рукой/ногой. Бонус применяется к ближнему бою и метательному оружию; он уже включён в таблицы ударов рукой/ногой. | Книга, стр. 48. Табличные значения приведены ниже; за BODY выше 13 не экстраполировать. |
| Навыки при создании | 44 очка распределяются между 11 навыками профессии (определяющий + 10 обычных), минимум 1 в каждый. Для прочих освоенных навыков доступно INT + REF очков. На создании рейтинг навыка максимум 6. | Книга, стр. 49; errata. Бонусы жизненного пути не повышают лимит; расовые бонусы могут. |
| База навыка | Основа = ведущий параметр + рейтинг навыка. Неизученный навык можно проверить, добавив только параметр. | Книга, стр. 50 и 57. Навык и модификаторы хранить раздельно. |
| Проверка сложности | Итог = d10 + Основа + потраченная Удача. Успех — итог строго выше СЛ; равенство считается провалом. Против СЛ противника сравнивается СЛ, равная соответствующему параметру противника ×3. | Книга, стр. 57–58. СЛ и ситуативные модификаторы задаёт ведущий; модификаторы прибавляются к СЛ. |
| Встречная проверка | Обе стороны бросают d10 + навык + параметр; больший итог выигрывает, при равенстве выигрывает защищающийся. | Книга, стр. 57. |
| Критический бросок | Натуральные 1 и 10 запускают дополнительный бросок: при 10 его прибавляют, при 1 вычитают из основы; если второй бросок равен 10, делается третий, направление определяется первым броском. | Книга, стр. 58. Броски показывать пошагово, не скрывать в одном бонусе. |
| Трудность и модификаторы | Базовые СЛ: лёгкая 10, средняя 14, сложная 18, очень сложная 20, практически невозможная 30. Примеры условий и освещения на стр. 58 меняют СЛ. | Книга, стр. 58. Это подсказки ведущему, не автоматическое определение ситуации приложением. |
| Развитие навыков и параметров | Следующий уровень навыка стоит текущий рейтинг; первый уровень стоит 1 очко. Навык с отметкой (2) стоит вдвое дороже. Параметр повышается за текущее значение × 10 очков улучшения; обычный предел — 10. | Книга, стр. 59; errata для исключений. |
| Дерево профессии | Профессия имеет три последовательные ветви. Повышение умения до ранга 5 открывает следующий узел этой ветви с рангом 0; пропускать предшествующие умения нельзя. Ранг узла повышается очками улучшения по общей таблице стоимости навыков. | Книга, стр. 59 и 61. |
| Удача | До броска игрок выбирает количество очков; каждое даёт +1 к проверке навыка или испытанию против смерти. Удача восстанавливается в начале игровой сессии. | Книга, стр. 47; errata. |
| Энергия | Стартовое значение задаётся профессией. Если стоимость магии за раунд в очках Выносливости выше Энергии, персонаж получает урон. Профессиональные умения могут повышать Энергию. | Книга, стр. 47 и профессии, стр. 38–46, 63, 65–66. Точный урон за превышение не задан в этом диапазоне — оставить ручным. |
| Социальное отношение | Территория и раса дают категорию из таблицы стр. 21. Равенство не даёт модификатора; опасение даёт +1 к Запугиванию и −1 к Харизме; терпимость даёт −1 к Соблазнению, Харизме, Убеждению и Лидерству; ненависть — −2 к тем же навыкам. | Книга, стр. 21. Для расы/территории без строки таблицы оставить ручной выбор ведущего. |
| Зависимость | Если персонаж не получает дозу, ежедневно бросает d10 ниже текущей WILL; провал даёт −5 к действиям, не связанным с объектом зависимости. WILL уменьшается на 1 за каждый день без дозы. При предложении дозы к d10 прибавляются дни без неё; провал означает, что персонаж принимает дозу. Через 21 день без дозы зависимость преодолена. | Книга, стр. 32. Хранить объект зависимости, дни без дозы и временную WILL; броски подтверждает игрок. |
| Репутация | При новой встрече бросается d10; при результате не выше репутации окружающие знают о персонаже. Проверка влияния известной репутации: d10 + WILL + уровень репутации; положительная репутация при успехе даёт +3 к связанным с ней социальным навыкам. | Книга, стр. 60. Репутацию назначает ведущий; приложение не придумывает её рост. |
| Штраф EV брони | EV вычитается из REF и DEX, минимум до 1; также применяется к Сотворению заклинаний, Проведению ритуалов и Наведению порчи. | Официальная errata, раздел об EV. Применять суммарный EV надетой брони; не складывать EV с весом. |
| Выносливость и восстановление | Нелетальный урон, магия и некоторые действия расходуют STA. ### Контрольные примеры

- BODY=6, WILL=5: B=5, поэтому HP=25, STA=25, REC=5, STUN=5. При SPD=8: RUN=24 м, LEAP=4 м. При BODY=6: ENC=60 кг, предел 300 кг, бонус урона +0, удар рукой 1d6, ногой 1d6+4.
- При весе 70 кг и BODY=6 превышение ENC составляет 10 кг: REF, DEX и SPD уменьшаются на 2.
- Проверка при параметре 7, навыке 4, d10=5 и заранее потраченной Удаче 2 даёт итог 18; она проходит СЛ 14, поскольку итог должен быть строго выше СЛ.

## 4. Различия профессий

По книге у каждой профессии пять игровых компонентов: определяющий навык, начальная Энергия, магические способности, набор навыков и стартовое снаряжение (стр. 37–46). Все девять профессий также имеют своё дерево из трёх ветвей (стр. 61–70).

| Профессия | Определяющий навык | Стартовая Энергия | Магический набор при создании |
|---|---|---:|---|
| Бард | Уличное выступление (Эмп) | 0 | Нет |
| Ведьмак | Подготовка ведьмака (Инт) | 2 | Все базовые знаки |
| Воин | Крепче стали (Тел) | 0 | Нет |
| Жрец | Посвящённый (Эмп) | 2 | 2 инвокации новичка, 2 ритуала новичка, 2 порчи низкой опасности |
| Маг | Магические познания (Инт) | 5 | 5 заклинаний новичка, 1 ритуал новичка, 1 порча низкой опасности |
| Медик | Лечащее прикосновение (Рем) | 0 | Нет |
| Преступник | Профессиональная паранойя (Инт) | 0 | Нет |
| Ремесленник | Быстрый ремонт (Рем) | 0 | Нет |
| Торговец | Бывалый путешественник (Инт) | 0 | Нет |

Профессиональные наборы навыков и стартовые предметы выбираются из таблиц соответствующей профессии. Воин выбирает 5 боевых навыков; остальные наборы заданы страницами профессий. Большинство профессий выбирает 5 предметов снаряжения, ведьмак — 2 плюс специальный комплект. Торговец дополнительно получает мула и повозку с обычными товарами общей стоимостью 1000 крон.

| Профессия | Ветки дерева умений |
|---|---|
| Бард | Обольститель; Информатор; Интриган |
| Ведьмак | Магический клинок; Мутант; Убийца |
| Воин | Стрелок; Охотник за головами; Потрошитель |
| Жрец | Проповедник; Друид; Фанатик |
| Маг | Политик; Учёный; Архимаг |
| Медик | Хирург; Травник; Анатом |
| Преступник | Вор; Атаман; Ассасин |
| Ремесленник | Оружейник; Алхимик; Импровизатор |
| Торговец | Посредник; Человек со связями; Гавенкар |

Правила выбора профессии зависят от расы: раса ведьмака и профессия ведьмака взаимосвязаны; Магом или Жрецом может стать человек или эльф. Эльф-жрец должен следовать человеческому божеству. Магические поля следует показывать по профессии, а не делать одинаково доступными всем персонажам.

Профессиональная ветвь хранится как данные: три направления, полученные умения, описания и рейтинги. Следующий узел ветви становится доступен с рангом 0, когда предыдущий достигает ранга 5; отдельные 5 очков за открытие не тратятся. Ранги навыков и умений дерева повышаются во вкладке «Развитие» по общей таблице стоимости навыков.

## 4.1. Развитие

- Начисленные ведущим очки хранятся раздельно с доступным остатком; каждое повышение списывает стоимость из доступного остатка.
- Повышение обычного навыка стоит столько очков, каков его текущий ранг; переход с 0 на 1 стоит 1. Для сложного навыка цена удваивается.
- Умения дерева профессии повышаются по той же таблице стоимости. Их нельзя улучшать, пока предыдущий узел ветви не достиг ранга 5.
- Повышение характеристики стоит её текущее исходное значение ×10; обычный предел исходного значения — 10. Расовые, постоянные и временные модификаторы не меняют цену.
- Основной лист показывает ранги навыков только для чтения. Изменять ранги можно во вкладке «Развитие»; характеристики настраиваются в отдельном диалоге из краткого заголовка группы навыков.

## 5. Версионирование и сохранение

- Каждая запись персонажа имеет постоянный `characterId`, `schemaVersion` и `rulesVersion`.
- Общая запись имеет формат `witcher-workshop-characters`, собственный `schemaVersion`, ID активного персонажа и массив независимых листов. Текущая схема — v6: последовательные миграции v1 → v2 добавляют жизненный путь, v2 → v3 — модификаторы характеристик и навыков, v3 → v4 — устойчивый ID профессии и выбор стартовых навыков, v4 → v5 — генерацию предыстории и хранение деревьев, v5 → v6 — баланс очков улучшения. Изменения автоматически сохраняются в локальном хранилище браузера.
- Справочник навыков хранит весь общий перечень с ведущими характеристиками. При выборе профессии лист помечает её определяющий навык и десять профессиональных навыков; навыки, выбираемые из набора, остаются отдельным явным выбором. Изменения профессии не удаляют введённые рейтинги: навыки прежнего набора остаются на листе как общие или дополнительные.
- Статические ссылки на предметы используют ID каталога; если предмет изменён или удалён, запись персонажа сохраняет имя и вес как снимок, чтобы старое сохранение не теряло данные.
- Базовое значение, временное состояние и модификатор хранятся раздельно. Правила не должны менять базовую характеристику при ранении, Death State или снаряжении.
- Экспорт JSON содержит всю запись персонажа и версию схемы; импорт сначала проверяет её, затем запускает миграции. Неизвестные поля сохраняются при повторном экспорте либо явно сообщаются пользователю.
- Старый одиночный инвентарь автоматически мигрируется в «Персонаж 1» с проверкой количества и веса; исходная запись остаётся в прежнем ключе браузера и входит в экспорт JSON.
- Полный импорт заменяет список персонажей только после подтверждения и оставляет локальную копию предыдущего сохранения. Старый JSON инвентаря импортируется как отдельный персонаж, не затрагивая существующие листы.
- При неизвестной будущей версии или ошибке проверки исходная запись не перезаписывается; пользователь может выгрузить исходный JSON и восстановить данные из проверенной резервной копии.
- Миграции формата должны идти последовательно на один номер за шаг; каждая миграция проверяется тестом на сохранение ID и введённых значений. При повышении `schemaVersion` исходный JSON сначала сохраняется в резервной копии, затем записывается проверенный результат.

## 6. Условия закрытия спецификации

Страницы 20–70 проверены: порядок создания персонажа, социальное отношение, девять параметров, производные значения, навык и его проверка, развитие и все профессиональные наборы/деревья сверены. Контрольные примеры выше фиксируют ожидаемые результаты для будущей реализации.

Остаются ручными до сверки других разделов книги: расчёт урона при превышении Энергии; цены и правила покупки стартового капитала; подробная токсичность, эффекты и стоимость алхимии/магии; полное состояние смерти и лечение критических ран. Если значение выходит за пределы таблиц стр. 47–48 (например BODY выше 13), его не экстраполировать. Социальное отношение к расам/территориям, отсутствующим в таблице стр. 21, выбирает ведущий.
